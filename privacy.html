SISREG Guard Enterprise

Privacy Policy

Last updated: August 11, 2026

SISREG Guard Enterprise is a browser extension developed to assist authorized healthcare organizations that use the Brazilian SISREG III (Sistema Nacional de Regulação).

The extension operates exclusively inside the official SISREG III website after the user has successfully authenticated.

1. Purpose of the Extension

The sole purpose of SISREG Guard Enterprise is to validate patient municipality information and prevent unauthorized workflow progression according to the configuration established by the healthcare organization.

  • Municipality validation
  • Workflow protection
  • Visual alerts
  • Institutional administrative controls

2. Data Collection

SISREG Guard Enterprise does NOT collect personal information.

The extension does NOT collect:

  • Personal information
  • Patient medical records
  • Passwords
  • Authentication tokens
  • Browsing history
  • Financial information
  • Location information
  • Email addresses
  • Usage analytics
  • Telemetry

3. Data Storage

The extension uses the browser Storage API exclusively to save local configuration required for its operation.

Stored Locally Purpose
Extension settings Local configuration
Authorized municipality configuration Municipality validation
Administrative preferences Extension operation

All stored information remains exclusively on the user's computer.

4. Data Transmission

SISREG Guard Enterprise:

  • Does NOT transmit information to external servers.
  • Does NOT send information to the developer.
  • Does NOT communicate with third-party services.
  • Does NOT use analytics platforms.
  • Does NOT use advertising services.
  • Does NOT sell user information.

5. Host Permission

The extension requests permission exclusively for:

https://sisregiii.saude.gov.br/*

No other websites are accessed.

6. Remote Code

The extension does not use:

  • Remote JavaScript
  • Remote WebAssembly
  • eval()
  • Dynamically downloaded executable code
  • External script execution

All executable code is packaged inside the extension.

7. Third Parties

No user information is shared with any third party.

8. Security

The extension executes only inside the official SISREG III environment. No information is stored outside the local browser storage.

9. Changes to this Policy

This Privacy Policy may be updated whenever necessary to reflect improvements or regulatory requirements.
