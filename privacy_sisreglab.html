Política de Privacidade — SISREG_Lab

Última atualização: 23 de setembro de 2026

1. Objetivo da extensão

O SISREG_Lab é uma extensão para navegadores que organiza e exibe informações de vagas de exames laboratoriais apresentadas no sistema SISREG. A extensão tem como finalidade facilitar a visualização da primeira vaga disponível de cada laboratório, considerando a data de disponibilidade e, em caso de empate, a menor cota.

2. Coleta de dados

O SISREG_Lab não coleta, armazena, vende, compartilha ou transmite dados pessoais dos usuários para terceiros.

A extensão não mantém banco de dados de usuários e não utiliza mecanismos de rastreamento, análise comportamental ou publicidade.

3. Acesso ao conteúdo do SISREG

Para cumprir sua única finalidade, a extensão precisa acessar as páginas do SISREG nas quais as informações de vagas laboratoriais são exibidas. O conteúdo necessário é processado localmente no navegador do usuário exclusivamente para organizar e apresentar essas informações.

A extensão não envia esse conteúdo para servidores externos e não o utiliza para finalidade diferente da organização e exibição das vagas.

4. Informações que não são coletadas

O SISREG_Lab não coleta ou armazena:

  • nome ou outros dados de identificação pessoal;
  • dados de saúde;
  • informações financeiras ou de pagamento;
  • senhas, PINs ou outras credenciais de autenticação;
  • comunicações pessoais;
  • localização;
  • histórico de navegação;
  • atividade do usuário, como cliques, teclas pressionadas ou movimentos do mouse;
  • conteúdo de páginas para qualquer finalidade diferente da execução da função da extensão.

5. Compartilhamento de dados

O SISREG_Lab não vende, aluga, compartilha ou transfere dados de usuários a terceiros.

6. Segurança

Como a extensão não mantém uma base de dados de usuários nem transmite dados pessoais para servidores externos, não existe armazenamento externo de dados pessoais realizado pelo SISREG_Lab.

7. Alterações nesta política

Esta política poderá ser atualizada caso o funcionamento da extensão seja alterado de forma que afete o tratamento de dados. A versão atualizada será publicada nesta mesma página, com a respectiva data de atualização.

8. Contato

Para dúvidas sobre esta Política de Privacidade ou sobre o funcionamento do SISREG_Lab, entre em contato com o responsável pelo projeto.
